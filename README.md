## 🚀 Что это

**Zona** — образовательная платформа, где **любой может быть и учеником, и преподавателем**.
Один и тот же код работает на **Android, Desktop (Windows/macOS/Linux) и в Web-браузере** —
благодаря Kotlin Multiplatform и Compose Multiplatform.

Интерфейс выполнен в **космической теме**: глубокий тёмный фон, анимированное звёздное небо,
неоновые градиенты-туманности (фиолетовый → голубой → розовый).

---

## 🪐 Какую проблему решает (актуальность)

> **Онлайн-образование фрагментировано и привязано к платформе.**

1. **Разрыв между «учиться» и «преподавать».** На большинстве площадок ученик и преподаватель —
   разные миры с разными приложениями. В Zona **преподаватель — это ученик, прошедший
   модерацию**: он сохраняет возможность самому проходить чужие курсы и нанимать наставников.
   Это отражает реальность: хороший педагог учится всю жизнь.

2. **Платформенная замкнутость.** Учебные приложения обычно живут только на телефоне *или*
   только в вебе. Zona — **единая кодовая база на три платформы**: студент занимается в браузере
   с ноутбука, продолжает с телефона, преподаватель ведёт курс с десктопа.

3. **Низкая вовлечённость.** Сухие видеолекции плохо удерживают. Zona объединяет
   **интерактивные упражнения с мгновенной проверкой, игровую систему XP, интервальные
   повторения (флеш-карточки по системе Лейтнера)** и живые занятия — то, что доказанно
   повышает запоминание и регулярность.

4. **Барьер входа для преподавателей.** Стать репетитором на классических площадках — долгая
   бюрократия. В Zona — **заявка из профиля с приложением документов (дипломов) и быстрой
   модерацией администратором**. Прозрачно и быстро.

**Аудитория:** изучающие языки и предметы, репетиторы и эксперты, желающие монетизировать
знания, образовательные кружки и онлайн-школы.

## ✨ Возможности

### Для ученика 🧑‍🚀
- 📚 **Каталог курсов** — красивые карточки, поиск, фильтр «Все / Мои», бесплатные и платные
- 🎓 **Запись на курс** с имитацией оплаты через внутренний кошелёк
- ✅ **Интерактивные уроки** — упражнения трёх типов (один вариант, несколько вариантов,
  ввод текста) с мгновенной проверкой
- ⭐ **Система XP и прогресс** — очки за правильные ответы, отслеживание прохождения уроков
- 🃏 **Флеш-карточки** — режим изучения с переворотом и **интервальными повторениями (Leitner)**
- 🛰 **Живые занятия** — групповые и индивидуальные, запись с оплатой
- 💬 **Чат** с преподавателями
- 💳 **Кошелёк** — баланс, пополнение, история операций (демо-валюта)

### Для преподавателя 🧑‍🏫
- Всё, что доступно ученику, **плюс**:
- 🛠 **Создание курсов** — название, язык, уровень, цена, обложка-эмодзи
- 📝 Добавление уроков и упражнений
- 📅 Создание групповых и индивидуальных занятий

### Для администратора 🛡
- ✅ **Модерация заявок** в преподаватели (просмотр мотивации и документов, одобрение/отклонение)

### Стать преподавателем 🌟
Любой ученик может из профиля подать **заявку с документами**. После одобрения админом роль
автоматически меняется на TEACHER — открываются инструменты преподавателя.

## 🛠 Технологии и архитектура

| Слой | Технологии |
|------|-----------|
| **UI** | Compose Multiplatform (Android · Desktop · Web/wasmJs) |
| **Архитектура** | Clean Architecture + **MVI** (однонаправленный поток данных) |
| **DI** | Ручной composition root (`AppGraph`) — работает на всех платформах |
| **Сеть** | Ktor Client (OkHttp / JS движки) |
| **Хранение** | multiplatform-settings (токен), Coil 3 (изображения) |
| **Сервер** | Ktor Server (Netty), слои `routing → service → dao` |
| **БД** | PostgreSQL / H2 + Exposed (узкие транзакции) |
| **Auth** | JWT (HMAC256), пароли — BCrypt |

### Принципы

- **Слои не протекают:** `domain` не знает про Ktor/Compose; `data` мапит DTO ↔ доменные модели;
  `presentation` (MVI Store) зависит только от `domain`.
- **Ошибки — по HTTP-кодам, а не по тексту:** единый `Outcome<T>` + `ErrorType`
  (`NO_CONNECTION`, `UNAUTHORIZED`, `CONFLICT`, `SERVER_ERROR`…).
- **Роли — enum, а не строки.**
- **Каждый экран** имеет состояния Loading / Empty / Error.

```
┌──────────────────────────────────────────────┐
│  UI (Compose)         ui/*                     │  рисует State, шлёт Intent
├──────────────────────────────────────────────┤
│  Presentation (MVI)   feature/*/presentation   │  Store: Intent→UseCase→State/Effect
├──────────────────────────────────────────────┤
│  Domain               feature/*/domain         │  интерфейсы репозиториев, модели
├──────────────────────────────────────────────┤
│  Data                 feature/*/data           │  API + маппинг DTO→domain
└───────────────────────────┬──────────────────┘
                            │  HTTP (Ktor)
┌───────────────────────────▼──────────────────┐
│  Server: routing → service → dao → Postgres    │
└──────────────────────────────────────────────┘
```

## ▶️ Запуск

> Требуется **JDK 17+**. БД по умолчанию — встроенная **H2** (отдельная установка не нужна).

### 1. Сервер
```bash
./gradlew :server:run          # Windows: gradlew.bat :server:run
```
Поднимется на `http://localhost:8080`. При первом старте создаются демо-аккаунты и контент.

**Демо-аккаунты:**
| Роль | Email | Пароль |
|------|-------|--------|
| 🛡 Администратор | `admin@zona.space` | `admin123` |
| 🧑‍🏫 Преподаватель | `teacher@zona.space` | `teacher123` |
| 🧑‍🚀 Ученик | `student@zona.space` | `student123` |

### 2. Клиент

**Desktop:**
```bash
./gradlew :composeApp:run
```

**Web (браузер):**
```bash
./gradlew :composeApp:wasmJsBrowserDevelopmentRun
```

**Android:** открыть проект в Android Studio, запустить конфигурацию `composeApp`
(эмулятор обращается к ПК по адресу `10.0.2.2:8080` — настроено автоматически).

### PostgreSQL вместо H2
```bash
export DATABASE_URL="jdbc:postgresql://localhost:5432/zona"
export DATABASE_USER="postgres"
export DATABASE_PASSWORD="postgres"
./gradlew :server:run
```

## 🧭 Сценарий демонстрации

1. Войти как **ученик** → каталог → открыть бесплатный курс → записаться → пройти урок → получить **XP**.
2. Открыть платный курс → ошибка оплаты → **кошелёк** → пополнить → записаться.
3. **Карточки** → изучить колоду (переворот, «помню / не помню»).
4. **Занятия** → записаться на групповое/индивидуальное.
5. **Профиль → Стать преподавателем** → заявка с документом.
6. Войти как **админ** → **Модерация** → одобрить заявку.
7. Снова ученик (теперь **преподаватель**) → вкладка **Создать** → новый курс.

## 📡 API (основное)

| Метод | Путь | Назначение |
|-------|------|-----------|
| POST | `/api/auth/register`, `/api/auth/login` | регистрация / вход |
| GET/PATCH | `/api/me` | профиль |
| GET | `/api/courses`, `/api/courses/my` | каталог / мои курсы |
| POST | `/api/courses/{id}/enroll` | запись (с оплатой) |
| GET | `/api/lessons/{id}/exercises` | упражнения урока |
| POST | `/api/exercises/{id}/submit` | ответ + начисление XP |
| GET/POST | `/api/decks`, `/api/cards/{id}/review` | карточки + повторения |
| GET/POST | `/api/sessions`, `/api/sessions/{id}/book` | занятия + запись |
| GET/POST | `/api/conversations`, `/api/conversations/{id}/messages` | чат |
| POST | `/api/teacher-application` | заявка в преподаватели |
| POST | `/api/admin/applications/{id}/approve` | модерация |
| GET/POST | `/api/wallet`, `/api/wallet/topup` | кошелёк |
